# التنزيل عن بُعد عبر GitHub Actions

هذه الإضافة تجعل خادم GitHub Actions ينزّل ملفاً من رابط HTTP/HTTPS مباشر، ثم تحفظه كـArtifact لتنزّله على هاتفك أو حاسوبك.

## التشغيل من الآيفون

1. افتح المستودع ثم تبويب **Actions**.
2. اختر **Remote Downloader (GitHub Actions)**.
3. اضغط **Run workflow**.
4. الصق رابط تنزيل مباشر في خانة `download_url`، ويمكنك كتابة اسم في `file_name`.
5. اضغط **Run workflow** وانتظر حتى تصبح الحالة خضراء.
6. افتح تشغيل Workflow ثم قسم **Artifacts**.
7. اضغط `downloaded-file` لتنزيل ZIP يحتوي الملف، ثم افتحه في تطبيق «الملفات».

## الحدود والتنبيهات

- هذه ميزة تنزيل ملفات وليست إنترنت VPN عاماً، ولا تجعل التصفح أو التطبيقات تستخدم اتصال GitHub.
- يجب أن يكون الرابط مباشراً ويمكن الوصول إليه دون تسجيل دخول أو تفاعل مع صفحة ويب.
- الحد المطبق في هذا الإصدار 2 GiB للملف و30 دقيقة للتنزيل؛ قد توجد أيضاً حدود GitHub Actions وحسابك.
- يحتفظ GitHub بالـArtifact ليوم واحد فقط.
- لا تستخدم روابط خاصة أو ملفات لا تملك حق تنزيلها. لا تضع كلمات مرور أو رموز وصول داخل الرابط.
- لا تضع أسراراً في اسم الملف أو الرابط؛ قد تظهر مدخلات التشغيل للمستخدمين الذين لديهم صلاحية رؤية سجل التشغيل.
- ملف الـArtifact يُنزّل كأرشيف ZIP من GitHub؛ بعد تنزيله على iPhone فك ضغطه من تطبيق «الملفات».

## ما الذي بقي كما هو؟

Workflow اختبار WireGuard وWorkflow Tailscale الحاليان لم يتم تعديلهما. إضافة Remote Downloader منفصلة حتى لا تغيّر إعدادات VPN الموجودة.
